# 🤖 CYBER ESCROW BOT

## 🔒 Telegram Escrow Bot

### Features
- 📊 User Stats
- 📋 Deal Management
- ⏳ Pending Deals
- 🌍 Global Statistics
- 👑 Admin Panel

### Setup Instructions

1. Clone the repository
2. Install requirements: `pip install -r requirements.txt`
3. Run: `python bot.py`

### Environment Variables (Render)
- `BOT_TOKEN`: Your Telegram Bot Token
- `GROUP_USERNAME`: @Staysafewithus_escrower
- `POWERED_BY`: @cyber_amit
